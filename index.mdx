## What Query Agent does

Query Agent accepts a natural language question and returns a structured data query DSL. Under the hood it runs a layered pipeline:

1. **LLM Extraction** — extracts `event`, `metric`, `time`, `region`, and `group_by` from your text
2. **Matcher Resolution** — maps extracted terms to canonical catalog entries
3. **Semantic DSL** — builds a normalized, human-readable representation of your query intent
4. **Exec DSL** — renders the executable payload sent to your downstream query system
