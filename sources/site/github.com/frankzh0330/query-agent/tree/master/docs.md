# Query Agent Documentation

[English](https://github.com/frankzh0330/query-agent/blob/master/docs/README.md) | [Chinese](https://github.com/frankzh0330/query-agent/blob/master/docs/README.zh-CN.md)

This folder collects the project documentation that used to live at the repository root. The root [README.md](https://github.com/frankzh0330/query-agent/blob/master/README.md) remains the main entry point, while this folder keeps architecture notes, evaluation docs, memory design notes, runtime notes, and diagrams together.

## Main Documents

- [ARCHITECTURE.md](https://github.com/frankzh0330/query-agent/blob/master/docs/ARCHITECTURE.md): current architecture, module ownership, runtime flow, and dependency direction
- [ARCHITECTURE.zh-CN.md](https://github.com/frankzh0330/query-agent/blob/master/docs/ARCHITECTURE.zh-CN.md): Chinese architecture document
- [EVALUATION.md](https://github.com/frankzh0330/query-agent/blob/master/docs/EVALUATION.md): eval harness, golden cases, and regression strategy
- [EVALUATION.zh-CN.md](https://github.com/frankzh0330/query-agent/blob/master/docs/EVALUATION.zh-CN.md): Chinese evaluation document
- [MEMORY.md](https://github.com/frankzh0330/query-agent/blob/master/docs/MEMORY.md): session, project, and user memory design
- [MEMORY.zh-CN.md](https://github.com/frankzh0330/query-agent/blob/master/docs/MEMORY.zh-CN.md): Chinese memory design document

## Runtime Notes

- [TELEGRAM\_TEST.md](https://github.com/frankzh0330/query-agent/blob/master/docs/TELEGRAM_TEST.md): Telegram testing notes
- [TELEGRAM\_TEST.zh-CN.md](https://github.com/frankzh0330/query-agent/blob/master/docs/TELEGRAM_TEST.zh-CN.md): Chinese Telegram testing notes

## Diagrams

- [diagrams/architecture.md](https://github.com/frankzh0330/query-agent/blob/master/docs/diagrams/architecture.md): Mermaid architecture diagrams
- [diagrams/sequence.md](https://github.com/frankzh0330/query-agent/blob/master/docs/diagrams/sequence.md): sequence diagrams
- [diagrams/flowchart.md](https://github.com/frankzh0330/query-agent/blob/master/docs/diagrams/flowchart.md): high-level flowchart
- [diagrams/matcher-sequence.md](https://github.com/frankzh0330/query-agent/blob/master/docs/diagrams/matcher-sequence.md): matcher sequence details
